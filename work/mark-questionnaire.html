SMC type 0x08 记号识别问卷

目标：为 Samilpo 2.0 的 type 0x08（CScoreView::DrawMark）逐项确认音乐含义，以便映射到 MusicXML。字形本身只有轮廓可依据——程序里没有任何字符串资源给出记号名称（已全量搜索 Shift-JIS / 889F / UTF-16 三种编码），所以必须由人眼判定。

1. 已确证的事实（不需要您回答）

  • MarkTB 在 engine.dll 0x1010059C，51 项 × 6 字节；第 0 字节是字体码，其余 5 字节在本版本全为 0。
  • DrawMark（0x10065570）取 glyph = MarkTB[MsgHdr+0x06]，用 DrawTextOut 画 1 个字符；位置 = obj+0x50/obj+0x52（X/Y）加缩放。MsgHdr+0x05==2 时走绝对定位分支。
  • 字体 Font\KAYAKUMA.TTF 是 Windows 符号字体，字体码 0xNN 渲染为 U+F0NN；glyph 名（U、comma…）是无意义占位名。
  • 全语料 8451 个 .smc 中 type 0x08 共 6707 条，只用到下表 14 个索引。所有记录的 headLen=0、flags=0，即记号除索引与位置外不带其他参数。
  • CSMMsg::Read 把 type 0x41 重映射为 0x08，但本语料中不存在 0x41。
  • obj+0x74/obj+0x75（= MsgHdr+0x03/+0x04）另有一套「音符上/下方记号」槽位，&0x7F 是索引、&0x80 是加圆括号；本语料中该两个字节全为 0，未使用。
