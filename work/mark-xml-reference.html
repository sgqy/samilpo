A. 奏法 articulations —— <notations><articulations> 子元素

长相元素名称长相描述与放置
<accent>重音记号 / accent实心 ＞ 形横楔。符头上/下方。与渐弱 hairpin 的区别：此为实心楔。
<strong-accent>
（即 marcato ^）		强重音 / marcato实心 ∧ 形竖楔，尖朝符头方向（type="up"/"down"）。
<staccato>断音 / staccato小实心圆点。符头上/下方。
<tenuto>持续音 / tenuto短横线一段。符头上/下方。
<detached-legato>断连音 / detached legato横线＋圆点竖排（上方放置时线在上、点在下）。
<staccatissimo>特短断音 / staccatissimo小竖楔（尖朝符头）或画作极小点。比 staccato 更短促。
<spiccato>跳弓记号 / spiccato短撇/水滴形斜笔。规范原文："a stroke articulation, as opposed to a dot or a wedge"。
<stress>加重 / stress官方配图为小的斜置楔笔（比 accent 窄小）。规范仅文字描述。
<unstress>减重 / unstress官方配图为小 U 形弧（开口朝上）。
<soft-accent>
（4.0 新增）		软重音 / soft accent空心菱形（官方配图）。
<scoop>起音上滑 / scoop从符头左下方弧线滑入音头（起音前）。
<plop>坠入音 / plop波线从上方坠入音头（官方配图；起音装饰）。
<doit>上扬甩音 / doit从音尾向右上方扬出的波线（官方配图）。
<falloff>坠落音 / falloff从音尾短促急落，比 doit 更陡更短。
<breath-mark>换气记号 / breath mark逗号形（4.0 亦可用 tick/燕尾形等取值）。
<caesura>完全停顿 / caesura双斜轨 "//"（railroad tracks）。

B. 弓法 / 技术记号 technical —— <notations><technical> 子元素

长相元素名称长相描述与放置
<up-bow>
弓法		上弓 / up-bowV 形两笔线。
<down-bow>
弓法		下弓 / down-bowП 形（上横杠＋两竖脚，开口朝下）。
<harmonic>泛音 / harmonic空心小圆（自然泛音）。官方无配图。
<open-string>空弦 / open string空心小圆——注意与 harmonic 同形，需靠上下文（是否伴随指法/弦号）区分。
<thumb-position>拇指把位 / thumb position空心圆下方带短竖柄。
<fingering>指法 / fingering裸数字（左手手指 1–5；0=空弦），直接以字符渲染。官方无配图。
<string>弦号 / string number圆圈内的数字。官方无配图。
<pluck>拨奏指示 / pluck文字（如 pizz.）。
<stopped>按弦止音 / stopped十字 ＋。
<snap-pizzicato>巴尔托克拨弦 / snap pizz.空心圆＋上方两撇须。
<double-tongue>双吐 / double tongue两道短斜杠竖向叠置。
<triple-tongue>三吐 / triple tongue三道短斜杠竖向叠置。
<bend>推弦 / bend上弯箭头。官方无配图。
<arrow>箭头 / arrow通用箭头（方向可变）。
罕见/文字型（不配图，仅列名，供排查用）：<open>(o)、<half-muted>(○加斜线)、<harmon-mute>、<hole>、<handbell>、<golpe>、<heel>、<toe>、<fingernails>、<flip>、<smear>、<brass-bend>、<hammer-on>、<pull-off>、<fret>(品号)、<tap>、<other-technical>

C. 装饰音 ornaments —— <notations><ornaments> 子元素

长相元素名称长相描述与放置
<trill-mark>颤音 / trill斜体 tr（长颤音后接水平波线，见下）。
<wavy-line>波线 / wavy line水平波线（tr 的延伸段；也可表长颤音/滑音）。
<mordent>下波音 / mordent锯齿波＋中间竖线穿过（线上下越出波纹；long 属性为加长波纹）。
<inverted-mordent>上波音 / inverted mordent纯锯齿波，无竖线（pralltriller）。与 mordent 的区分就在这条竖线。
<turn> / <delayed-turn>回音 / turn横躺 S（双环曲线）。delayed-turn 字形相同、演奏时机不同。
<inverted-turn> / <delayed-inverted-turn>回音（倒） / inverted turn与 turn 互为上下翻转的横躺 S（官方配图无竖线；另有 vertical-turn 变体）。
<schleifer>滑奏装饰 / schleifer长而斜的锯齿（快速滑入）。
<tremolo>震音 / tremolo符干侧 1–3 道斜杠。
<shake> （罕见）摇摆音 / shake一段波线（旧式摇摆颤音；官方配图与 wavy-line 形似）。
极罕见：<haydn>（海顿装饰）、<vertical-turn>/<inverted-vertical-turn>（竖排回音变体）、<other-ornament>；装饰音旁可附 <accidental-mark>（♯ ♭ ♮ 临时记号）。

D. 波线与滑线 —— <notations> 直属元素（易与 C 类混淆）

长相元素名称长相描述与放置
<arpeggiate>琶音线 / arpeggio竖向波线，跨多个音符。
<non-arpeggiate>禁止琶音 / non-arpeggio竖方括号。
<glissando>滑音 / glissando斜直线（可带 "gliss." 文字或箭头），连接两音。
<slide>滑奏 / slide外观同为直线——与 glissando 同形不同义（铜管/竖琴滑音）。

长相元素名称长相描述与放置
<fermata>
type="upright"（默认）		延长记号（正） / fermata上拱弧＋弧内点。倒立形用 type="inverted"（官方无单独配图，形状为上下翻转）。

F. 力度 dynamics 与渐变 wedge

长相元素名称长相描述与放置
<dynamics> → p pp mp mf f ff sf sfz fz fp rfz …力度符号 / dynamics衬线粗斜体字母组合；非字母组合用 <other-dynamics>。
<notations><wedge type="crescendo">渐强 / crescendo hairpin两条细实线张开（渐弱 diminuendo 反向收拢）。注意与实心 accent 楔区分。官方无配图。

G. 其他（direction / 兜底）

长相元素名称长相描述与放置
<direction><segno>反复起始 / segno粗斜线＋S＋上下两点。
<direction><coda>尾声 / coda椭圆＋十字。

同形易混对照（人工比对时最先出错的几组）

形状家族成员与区分点
楔形accent（实心＞）vs wedge 渐强/渐弱（两条细线）vs strong-accent（竖向 ∧）vs staccatissimo（小竖楔）
空心圆harmonic vs open-string（官方图同形）vs <open>(弱音器开孔) vs thumb-position（圆下带短柄）vs segno 上的点——靠上下文与附加笔画区分
波线家族arpeggiate（竖向）vs wavy-line（横向）vs mordent（中央竖线穿过）vs inverted-mordent（无竖线）vs schleifer（长斜锯齿）
V 形up-bow（两笔线）vs accent（实心楔）vs hairpin 渐弱（两条细线合拢）
横线tenuto（短线一段）vs pedal 续线（跨小节长线，常配 Ped.）vs glissando（斜直线）
圆点staccato（独立小点）vs fermata 弧内的点（必伴随弧）
数字/字母fingering（裸数字）vs string（圈内数字）vs tremolo 斜杠条数 vs 力度字母（衬线粗斜体）
