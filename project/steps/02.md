## 二、执行记录

### 步骤 1 — 复现阶段一结论（未重新探索）

按任务书要求先读取 `project/research-state.md` / `project/function-index.md` / `docs/smc-format.md` / `project/open-questions.md` / `tools/smc_walk.py`。
确认阶段一结论可用，未推翻既有结构；被要求澄清的「0x19 是否歌词」在第 4 步获得直接证据。

### 步骤 2 — 定位 CKCConv 全链路（engine.dll）

反编译并记录：

- `CKCConv::Open` 0x10030B10：id 1..6 → `FUN_100306b0` 两次（正向表 + 反向表）。
- `FUN_100306b0`：`u16 n, lo, hi`，然后**每区间**读取 `(u16 start, u16 end, u16 data[])`，条目数 = `(((end-start)>>8)+1)*(hi-lo+1)`。
- `FUN_100308c0`：查表；越界或值为 0 时返回输入码位。
- `CKCConv::ToUnicode/FromUnicode/Convert/ConvertFont/GetCodeName`：字符串/单字符/字体名三种转换与 id 名称表。

**发现并修正一处阶段一错误**：初版 `.cod` 解析器按「先全部 start/end、后全部 data」读取，实际为每区间 `(start,end,data)` 紧邻。修正后所有 `.cod` 字节恰好用尽（889F 0x451A 正向 + 反向 = 文件长）。

### 步骤 3 — 确定 id ↔ 文件映射与「SMC 用哪个编码」

- 在 exe 中扫描 `push imm32` 引用 `*.cod` 字符串的立即数，得到 5 个调用点。
- 切换 Ghidra 目标到 MusicBook.exe，反编译 `FUN_00418980`（InitInstance），按调用顺序读出 `CKCConv::Open(3,\F040a.cod)`、`(4,\F040b.cod)`、`(1,\889F.cod)`、`(2,\B0a1.cod)`、`(6,\KS.cod)`。
- 反编译 engine.dll `MyDrawTextOutW` 0x10096530（并核对汇编）：`ToUnicode(3,…)` 求长度 + `ToUnicode(1,…)` 转换 → **SMC 文本使用 id 1 = 889F**。

### 步骤 4 — 验证解码（本地 Python）

`tools/smc_text.py` 实现码表解析与解码：

- 全语料 8451 个 `.smc` 曲名：889F 全部解出韩文；B0a1/Ks/F040a 对照组全部失败 → 唯一正确表。
- 抽样 300 个文件各消息类型 head 扫描 → 韩文只出现在 0x19 与 0x06。
- 歌词 head 与文本框 head 的详细转储写入 `raw/head_dump.txt`（UTF-8）。
- 修正了探针自身的统计杂质（控制台编码导致的 `\ufffd`、把 ASCII 计入「非韩文」的启发式），确认解码本身无误。

### 步骤 5 — 确认 0x19 = CSMLyricMsg

- xref `MyDrawTextOutW` → 调用者含 `CSMLyricMsg::DrawMsg` 0x1009AD00（导出名即类名）。
- xref `CSMLyricMsg::ctor` 0x1009AC20 → 调用者含 `CScoreView::DrawTextMsg` 0x1005EBB0（构造副本并绘制）。
- `CSMDoc::GulsamToSMC_Lyrics` 0x10030010 直接写入 `type = 0x19`、`headLen = 文本长度 + 0x10` —— 结构直接证据。

### 步骤 6 — head 字段与关联机制（统计验证）

- head 长度 = `0x10 + head[0x0C]`，**9129/9129** 条成立。
- 字段偏移与取值统计（字体索引 {1,2,3,5,6,7}、字号 {13,14}、颜色恒 0、样式多为 0）。
- 父对象统计：**2961/2961 条歌词的父消息类型 = 0x01**（音符）；`lyric_key - note_key ∈ {+1: 3000, +2: 259}`。
- 还原完整歌词序列（`500KFS-0041.smc`：`바다의 노래`）证明顺序与关联正确。

### 步骤 7 — 相邻结构：0x06 TLV

反编译 `CSMTextMsg::DrawMsg` 0x100C2F70 得到标签表，`tools` 探针在 400 个文件上验证 **1991/1991** 条记录解析成功。
